MYCAREER MAP — Zero-cost prototype
===================================

Open index.html in a modern browser. No installation or build step is required.

Included in this prototype:
- Illustrated career-world landing page
- Six clickable career worlds and career cards
- 10-question gamified interest discovery
- Local transparent career matching demo
- Career Navigator question/answer demo
- Education pathway explorer with route tabs
- Printable Future Passport

Important:
- The current "AI Career Navigator" is a local rule-based demo, NOT a live generative AI integration.
- Career match percentages are illustrative prototype scores, not validated psychometric results.
- Education pathways are simplified examples. Verify exact entry requirements, accreditation, costs and current programme availability with official institutions and relevant authorities.
- No personal information is sent to a server. The demo runs in the browser.
- Google Fonts is optional; if offline, the page uses fallback fonts.

Suggested next development steps:
1. Validate the quiz questions with students and a teacher/career guidance practitioner.
2. Research and cite official Malaysian education pathway sources for each career.
3. Replace placeholder route descriptions with institution-verified details.
4. Add a secure backend for a real AI API. Never expose an API key in public front-end code.
5. Test usability and measure whether students better understand their post-SPM options.
